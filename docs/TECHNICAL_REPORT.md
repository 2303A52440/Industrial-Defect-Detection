# Technical Report: On-Device Edge AI Industrial Quality Control Assistant

## Executive Summary
This technical report details the design, implementation, and evaluation of an on-device, dual-pipeline Edge AI system for real-time visual inspection of manufactured components (e.g., steel plates, metal surfaces, printed circuit boards). Designed specifically for **Raspberry Pi 5** and Arm-based edge hardware (with optional **Hailo AI HAT+** hardware acceleration), the system achieves sub-50ms visual defect detection alongside on-device LLM reasoning using **Llama 3.2** deployed via **ExecuTorch**.

The system employs a strict separation of concerns across two edge hardware processing units:
1. **Vision Inference Engine (Hailo NPU / Arm CPU)**: Focuses on low-latency frame parsing, object detection, and anomaly contour segmentation.
2. **Advisory & Reasoning Engine (Llama on ExecuTorch Arm CPU)**: Processes structured metadata output from the vision engine and generates contextual, operator-facing remediation steps.

## Core Technologies & Hardware Stack

| Layer | Component | Description & Rationale |
| :--- | :--- | :--- |
| **Edge Hardware** | Raspberry Pi 5 (8GB) | quad-core Arm Cortex-A76 @ 2.4GHz CPU for ExecuTorch Llama host execution. |
| **NPU Accelerator** | Hailo AI HAT+ (13/26 TOPS) | Low-power neural processing unit running HailoRT VStreams API for high-FPS visual inspection. |
| **Vision AI** | YOLOv8-Nano / Anomaly Engine | Fine-tuned on **NEU Surface Defect Dataset** (Cracks, Inclusion, Patches, Pitted Surface, Scratches). |
| **LLM Runtime** | **ExecuTorch** | PyTorch's edge runtime enabling quantized Llama 3.2 execution on Arm CPUs with minimal RAM footprint. |
| **LLM Model** | **Llama 3.2 (1B / 3B Instruct)** | INT4 / INT8 quantized `.pte` model delivering concise factory floor remediation guidelines. |
| **Operator UI** | Streamlit + OpenCV | Web-based real-time visual inspection feed, advisory cards, and historic SQLite telemetry logs. |

## Defect Classification & Severity Rules Engine

Defects are mapped to standard NEU Industrial categories and assigned a severity level:

$$ \text{Severity Grade} = \begin{cases} \text{CRITICAL} & \text{if } \frac{\text{Defect Area}}{\text{Image Area}} > 0.05 \text{ or Confidence } \ge 0.75 \\ \text{MEDIUM} & \text{if } \frac{\text{Defect Area}}{\text{Image Area}} > 0.02 \text{ or Confidence } \ge 0.50 \\ \text{LOW} & \text{otherwise} \end{cases} $$

### Action Matrix
- **CRITICAL**: Component scrap required. Immediate line interlock alert generated by Llama.
- **REWORK**: Surface grinding or automated polishing cycle triggered at Station 4.
- **PASS WITH MONITORING**: Minor cosmetic imperfection logged for trend analysis; component proceeds on conveyor line.

## Installation & Deployment Guide

### 1. Prerequisites on Raspberry Pi OS
```bash
sudo apt update && sudo apt install -y python3-opencv python3-pip sqlite3
pip install -r requirements.txt
```

### 2. Hailo NPU Setup (Optional for AI HAT+)
```bash
sudo apt install -y hailo-all
hailortcli fw-control identify
```

### 3. Launching the Operator Dashboard
```bash
python -m streamlit run src/dashboard/app.py
```

### 4. Running the Batch CLI Demo Simulator
```bash
python scripts/demo_simulator.py
```

## Conclusion
The system proves that complex dual-pipeline edge workflows—combining real-time computer vision with local LLM reasoning—can be effectively deployed on low-cost SoC platforms like Raspberry Pi 5. By offloading vision tasks to the Hailo NPU and running ExecuTorch Llama on the Arm CPU, factory operators gain zero-latency visual defect detection paired with intelligent, actionable guidance.
